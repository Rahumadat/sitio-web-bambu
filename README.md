# Escuela de Lenguaje Bambú — Sitio Web

Sitio web oficial (One-Page) de la Escuela de Lenguaje Bambú. Educación inicial
especializada en el desarrollo del lenguaje. 15 años de trayectoria desde 2009.

## Tecnologías
- HTML5 + CSS3 personalizado
- Bootstrap 5 y Bootstrap Icons (vía CDN)
- Google Fonts
- Sitio 100% estático y responsivo

## Estructura
```
Sitio_Web_Bambu/
├── index.html          # Página principal
├── css/
│   ├── styles.css      # Estructura y estilos base
│   ├── theme-a.css     # Tema activo: Bambú & Dorado
│   ├── theme-b.css     # Tema alternativo: Cielo & Girasol
│   └── theme-c.css     # Tema alternativo: Lavanda & Salvia
└── assets/             # Imágenes (logo, equipo, pandas, etc.)
```

## Ver el sitio localmente
Abre `index.html` en el navegador (doble clic). Requiere conexión a internet
para cargar Bootstrap, los íconos y las fuentes desde sus CDN.

## Publicación en GitHub Pages
1. Sube el proyecto a un repositorio de GitHub.
2. En el repo: **Settings → Pages**.
3. En "Build and deployment", elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`. Guarda.
5. En unos minutos el sitio queda disponible en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`
